# Portfolio Site

![Homepage light theme](./src/assets/images/portfolio-light.png 'Screenshot of portfolio homepage light theme')
![Homepage dark theme](./src/assets/images/portfolio-dark.png 'Screenshot of portfolio homepage dark theme')

angelrod.dev is a personal developer portfolio built with React and Vite. It features a warm minimalism editorial design with light and dark themes, smooth scroll navigation, and a single-page narrative layout.

## Sections

- **Hero** - Typography-driven intro with animated CTAs
- **About** - Bio with profile photo and categorized tech toolkit
- **Experience** - Tabbed layout for work history and education
- **Projects** - Featured project showcases with an interactive filterable grid
- **Contact** - Inline section with mailto CTA and social links

## Tech Stack

- React 18
- Vite
- CSS custom properties for theming
- Google Fonts (Playfair Display, Inter, JetBrains Mono)
- Intersection Observer for scroll-spy and animations
- react-icons

## Development

```bash
npm install
npm run dev
```
